# FL-26-Plattform
FL26 KIT STUDIO – VERSION 1

START ON IPAD
1. Download index.html to the Files app.
2. Open it from Files in Safari (or serve it from a static website).
3. Use the Database tab to search the preloaded FootyLogos team index.
4. Add a kit by pasting a direct PNG URL or selecting an image file.
5. Use Designer with an existing working FL26 512x768 texture as the base.
6. Export PNG and host it at a public direct-image URL before importing it into Football League 2026.

DATA & PRIVACY
- Team list is a starter index based on the 90 teams shown on FootyLogos when researched (it includes national teams as well as clubs); it is NOT a verified full roster of every team inside the game.
- Your custom entries are stored in the browser's localStorage on the device/browser you use.
- Export a JSON backup regularly. Local image uploads are stored as data URLs and may use browser storage quota.
- The app does not upload, host, or automatically scrape third-party kits.

DESIGNER LIMITATIONS
- The editor overlays color and simple patterns across the entire uploaded image.
- It does not know the game's UV map, cannot isolate shirt/shorts/socks, and cannot guarantee a correct in-game result.
- Start with a texture already known to work in FL26. Export is always 512x768 PNG.

HOSTING
For persistent access on iPad, publish this static index.html with a free static host such as GitHub Pages. The HTML file itself is standalone; no paid backend or account is required to run it locally. Public image hosting is separately required for newly created PNGs to get direct URLs usable by the game.

Officially documented FL26 kit format and import steps: https://www.footylogos.com/football-league-game/kits
